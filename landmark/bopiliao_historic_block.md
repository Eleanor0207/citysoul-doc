# 剝皮寮歷史街區 史實研究記錄範本

> 用途：查資料的過程中直接記錄在這裡，之後整批轉成 `landmarks/bopiliao_historic_block.yaml`→ 寫入 `brain.landmark_souls`。
> - `spirit_id`：`bopiliao_historic_block`（2026-08-13 定案）
> 這份文件本身不是正式資料來源，是給 Lead 審核前的**草稿暫存區**。
>
> ⚠️ 提醒：剝皮寮是**街區型地標**，不是單一建物，實際查資料時要留意：
> 1. 「靈魂」要代表整個街區的集體記憶，還是某個具體時期/店家意象？這會影響 `archetype` 怎麼設計，建議先記錄、之後再跟人格層一起討論。
> 2. 街區保存過程涉及都更/居民遷離的歷史，屬敏感敘事，處理方式同「爭議區」流程。
> 3. 地名由來（「剝皮」）本身有多種民間說法（剝樹皮/剝獸皮等），版本分歧，記得標 confidence。

## 0. 欄位結構（擴充版）

`brain.landmark_souls.founding_facts` 原本是 `{year, event, detail}`，研究階段建議多記兩欄：

```jsonc
{
  "year": "清代",
  "event": "街區形成",
  "detail": "...",              // ≤ 50 字，一句話講完
  "source": "...",
  "confidence": "..."           // 見下方分級
}
```

> JSONB 結構，**不需要跑 migration**——這是團隊內部約定，不是 DB schema 變更。

### confidence 分級

| 等級 | 意思 | 後續處理 |
|---|---|---|
| `official` | 台北市文化局 / 官方保存計畫文獻 / 學術考據一致 | 直接可進 `founding_facts` |
| `mainstream` | 主流說法，多數資料一致但非官方認證 | 可進，措辭保守 |
| `disputed` | 地名由來、都更爭議、居民遷離等敘事分歧 | **先不進 founding_facts**，記在下方「爭議區」 |

## 3. 文化意義（對應 `cultural_significance`，自由敘述，建議 150–250 字）

草稿：
> 剝皮寮歷史街區是艋舺（萬華）都市發展的活化石。它獨特的彎曲巷弄紋理保存了清代縱貫道路的聚落脈絡，而廣州街一側帶有亭仔腳與裝飾山牆的牌樓厝，則記錄了日治市區改正的近代化軌跡。因長期劃為學校預定地禁建，使這裡意外凍結了跨越兩百年的建築風格——從清代紅磚土角厝、日治洋樓到戰後常民生活痕跡完好並存。剝皮寮不僅代表煤炭市集、印刷廠、茶桌仔店與販仔間所交織的庶民勞動記憶，更見證了臺灣文化資產保存與都市更新共存的轉型歷程。

## 5. ⚠️ 爭議區（confidence = disputed 的項目集中放這裡）

> 常見爭議點：地名由來的多重民間說法、保存運動與都更/居民權益的敘事立場、日治市區改正的政治解讀。這些不會自動進 `founding_facts`。

| 內容 | 分歧點 | 是否涉及敏感敘事（居民權益/政治/認同等） | 處理建議 |
|---|---|---|---|
| 地名「剝皮」由來 | 說法一：清代從福州運木材至此進行「剝樹皮」加工。<br>說法二：與早年養殖與動物屠宰「剝獸皮」有關。<br>說法三：源自閩南語轉音（北皮藔 ➔ 福皮藔 ➔ 剝皮寮）。 | 否（單純考據與民間傳說分歧） | 不直接納入 `founding_facts` 的定論，可於文史介紹中以「多重說法並存」方式呈現。 |
| 老松國小擴建與居民遷離 | 1980-1990年代政府徵收土地過程中，部分住戶對拆遷補償、居住權利與校地預定地需求產生激烈爭執與歷史傷害記憶。 | 是（涉及居住權、都市更新衝突與居民離散記憶） | 屬於敏感常民歷史，**不寫入 founding_facts**。若角色對話提及，應保持中立包容立場，側重歷史記憶紀錄而非評斷對錯。 |
| 日治市區改正之歷史評價 | 一方強調市區改正帶來近代衛生與道路建設；另一方認為破壞清代原有古街門面與傳統紋理。 | 是（涉及 colonial 治績評價與歷史觀認同） | 側重建築空間形態變化（前門變後巷、牌樓厝出現）客觀描述，避免主觀立場用語。 |
