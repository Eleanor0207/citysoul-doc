## ⚠️ 內容邊界提醒

這個地標的前身是日治時期「臺北北警察署」，建館主旨是紀念 1920 年代台灣文化協會、台灣民眾黨等**反殖民、追求文化與政治自主**的社會運動（蔣渭水等人相關史蹟）。跟中正紀念堂不同，這段歷史在台灣社會**普遍被視為civic/文化資產保存的正面敘事**，黨派分歧程度低很多，但仍有兩個地方要留意：

1. **殖民時期的歷史定性描述**：日治時期本身的政治定性（統治 vs 殖民等用詞選擇）建議保守，跟其他日治時期地標（松山文創、榕錦時光）同一套原則
2. **歷史人物與當代政治連結**：蔣渭水等歷史人物有時會被不同政治立場援引詮釋為自己陣營的精神先驅，查資料時如果看到「某某政黨/立場認為蔣渭水代表什麼」這類論述，記錄來源但先歸類為爭議區，不要直接當作角色史實

  "year": "1921",

  "detail": "...",              // ≤ 50 字，一句話講完
  "source": "...",
  "confidence": "..."           // 見下方分級

> JSONB 結構，**不需要跑 migration**——這是團隊內部約定，不是 DB schema 變更。

### confidence 分級

| 等級 | 意思 | 後續處理 |
|---|---|---|
| `official` | 官方（紀念館本身）文獻 / 學術考據一致 | 直接可進 `founding_facts` |
| `mainstream` | 主流說法，多數資料一致但非官方認證 | 可進，措辭保守 |
| `disputed` | 版本分歧，或涉及歷史人物的當代政治詮釋差異 | **先不進 founding_facts**，記在下方「爭議區」 |
