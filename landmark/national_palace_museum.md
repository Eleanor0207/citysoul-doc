## ⚠️⚠️ 這個地標的敏感性質，與現有 SDD 治理框架不完全對應——需要 Lead 特別決策

SDD `SDD_v2_1_Unity_3D.md` §12.2 為龍山寺設計了一整套內容治理流程（`taboo_topics` 擴充、`not_this_character`、B4/B5 邊界強化等），但那套設計的假設前提是**宗教教義爭議**。故宮牽涉的敏感性質不同、但風險等級可能同樣高：

- 文物來源涉及 **1949 年遷台**的歷史背景，本質上與兩岸關係、政治史觀直接相關
- 文物**歸屬/是否應歸還**在兩岸與國際上都有持續爭論
- 「國立」定位本身、機構名稱與定位，在不同政治立場下有不同敘事方式
- 這類內容不是「教義性陳述」問題，是**政治立場中立性**問題——性質上更接近 SDD 對 Claude 自身「政治敏感話題保持中立、給事實而非個人立場」的要求，而不是宗教禁忌

**現有 `character_personas.taboos` / `not_this_character` 欄位結構可以沿用**，但**內容設計邏輯需要重新想過**，不能直接套龍山寺那組（不代替神明給指示、不預測吉凶……這些對故宮沒有意義）。建議提早跟 Lead 討論是否需要比照 §12.2 另訂一節「故宮政治敏感內容治理」，而不是等到 Phase 3 前才發現這個缺口。

**查資料階段的具體建議**：只記錄機構沿革、建築、典藏制度等中性事實；任何涉及「文物該不該還」「兩岸關係如何定性遷台事件」的內容，一律不要當作可注入 prompt 的史實，直接記錄在下方「政治敏感區」（獨立於一般爭議區），供 Lead 決定是否需要專門設計的迴避話術。

## 0. 欄位結構（擴充版）

```jsonc
{
  "year": "1965",
  "event": "臺北外雙溪新館落成",
  "detail": "...",              // ≤ 50 字，一句話講完，避免帶政治史觀措辭
  "source": "...",
  "confidence": "..."           // 見下方分級
}
```

> JSONB 結構，**不需要跑 migration**——這是團隊內部約定，不是 DB schema 變更。

### confidence 分級

| 等級 | 意思 | 後續處理 |
|---|---|---|
| `official` | 官方（故宮本身）文獻 / 學術考據一致，且**不涉及政治立場敘事** | 直接可進 `founding_facts` |
| `mainstream` | 主流說法，多數資料一致但非官方認證 | 可進，措辭保守、去政治化 |
| `disputed` | 版本分歧（一般史實層面） | 記在「一般爭議區」 |
| `political` | **涉及兩岸關係/文物歸屬/史觀定性** | 記在「政治敏感區」，**不進 founding_facts**，等 Lead 決策 |

## 3. 文化意義（對應 `cultural_significance`，自由敘述，建議 150–250 字，去政治化措辭）

草稿：
> 國立故宮博物院（臺北外雙溪正館）是全球典藏華夏歷代藝術精粹與青銅、玉器、陶瓷、書畫重寶的頂尖博物館之一。其正館建築由建築師黃寶瑜設計，於1965年落成，以中國傳統宮殿式建築結構與綠瓦黃牆造型著稱，並於2020年獲登錄為歷史建築。外雙溪故宮保存了自宋、元、明、清歷代宮廷累積的近70萬件稀世珍寶，如翠玉白菜、肉形石、毛公鼎與《富春山居圖》等。故宮不僅代表了東亞傳統工藝美學與物質文化的極致高峰，其典藏研究與數位化展演，更使其成為全世界當代視覺文化與歷史研究最重要的樞紐之一。

## 6. 🔴 政治敏感區（confidence = political，獨立於一般爭議區，不自動處理）

> 每一條都要標明：這是查資料時**自然會遇到**的政治敘事（如維基百科条目本身的措辭），還是玩家**可能主動詢問**的方向（如「這些文物是不是該還給對岸」）。兩者處理邏輯不同——前者只是你查資料時要避開，後者需要在人格設計階段準備轉向話術。

| 內容 | 屬於查資料時遇到 / 玩家可能主動問 | 建議處理方向 |
|---|---|---|
| 1948-1949年文物遷臺之政治史觀定性 | 查資料時自然會遇到（「文物搶運」vs「國寶避難與保護」） | 於 `founding_facts` 中**嚴禁採用具立場之名詞**，統一採用中性動詞「精選文物運臺與保存」。 |
| 故宮文物歸屬與跨國/兩岸歸還爭議 | 玩家可能主動問（「文物屬於誰？是否該歸還？」） | 保持嚴格政治中立立場。**角色不發表歸屬判斷**，將話題中性引導至「文物作為人類共同文化遺產之保護與欣賞」。 |
| 「國立故宮博物院」機構名稱與去中國化爭論 | 兩者皆可能遇到（改名提案、行政院改隸討論） | 採用目前官方與文化資產登記之法定名稱「國立故宮博物院」，不加入任何政黨或政治立場評價。 |
