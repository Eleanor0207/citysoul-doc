## 0. 欄位結構（擴充版）

`brain.landmark_souls.founding_facts` 原本是 `{year, event, detail}`，研究階段建議多記兩欄：

```jsonc
{
  "year": "1908",
  "event": "落成",
  "detail": "...",              // ≤ 50 字，一句話講完
  "source": "...",
  "confidence": "..."           // 見下方分級
}
```

> JSONB 結構，**不需要跑 migration**——這是團隊內部約定，不是 DB schema 變更。

### confidence 分級

| 等級 | 意思 | 後續處理 |
|---|---|---|
| `official` | 官方文獻 / 文化局資料 / 學術考據一致 | 直接可進 `founding_facts` |
| `mainstream` | 主流說法，多數資料一致但非官方認證 | 可進，措辭保守 |
| `disputed` | 版本分歧、敘事立場有爭議（如日治時期定位、拆遷爭議） | **先不進 founding_facts**，記在下方「爭議區」 |

## 3. 文化意義（對應 `cultural_significance`，自由敘述，建議 150–250 字）

草稿：
> 西門紅樓是臺北西區跨越百年的娛樂文化與常民生活縮影。從日治時期臺灣第一座公營市場「新起街市場」，到戰後京劇滬園劇場、說書紅樓書場、放映二輪國片與洋片的紅樓戲院，紅樓始終屹立於西門町流行文化的浪潮中心。其大膽的八角堂與十字樓建築結構，融匯了西洋近代鋼骨結構與傳統鎮邪寓意。進入21世紀後，紅樓從大火殘垣中浴火重生，轉化為文創孵育基地與多元性別包容的露天聚落。它不僅是一座古蹟，更是一座持續吸納新舊文化、交織族群與次文化的當代城市地標。

## 5. ⚠️ 爭議區（confidence = disputed 的項目集中放這裡）

> 紅樓的爭議點常見於：日治時期定位敘事、特定歷史事件的政治解讀、周邊性別/次文化空間的敏感呈現方式。這些不會自動進 `founding_facts`。

| 內容 | 分歧點 | 是否涉及敏感敘事（政治/認同/性別等） | 處理建議 |
|---|---|---|---|
| 八角與十字造型的風水鎮邪傳奇 | 一方認為僅為建築師近藤十郎對幾何空間設計與通風採光的創新實驗；民間傳說則強調八角形為八卦、十字形為西洋十字架，用以鎮壓日治初期墓葬區煞氣。 | 否（民間傳奇與建築學考據之分歧） | 不放入 `founding_facts` 的正式建築史實，可作為角色趣味對話或文化傳說解鎖素材。 |
| 日治殖民建設之歷史定位 | 官方建築史強調其為近代公營市場現代化示範；部分語境則討論其早期主要服務日本移民而具階級/殖民隔閡。 | 是（涉及政治與殖民歷史認同解讀） | `founding_facts` 中保持客觀建築與都市計劃事實描述，避免帶有主觀政治評價的詞彙。 |
| 性別/露天酒吧次文化空間的呈現 | 紅樓南廣場為台北著名同志次文化聚落，在遊戲設定與對話敘事中需考慮呈現的開放度與尺度邊界。 | 是（涉及性別多元議題與年齡分級考量） | 側重「多元包容與友善聚落」之正面文化意義，不寫入傳統史實表格，放至人格與性別治理規範中規範。 |
