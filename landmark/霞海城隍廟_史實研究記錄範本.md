## ⚠️ 特別提醒：這座廟的高風險問題方向，比龍山寺更集中

霞海城隍廟以**月老（月下老人）**聞名，是台北最知名的姻緣廟之一。這代表：

`citysoul_data_schema.md` §7 記載龍山寺現有四條禁忌之一是「**不預測個人吉凶姻緣財運**」——這條在龍山寺是四條之一，但**在這裡幾乎會是玩家最常問的問題**。查資料與設計人格時建議提早假設：「我什麼時候會遇到對象」「這個人適不適合我」「該不該追」這類問法會是高頻情境，不是邊緣案例。

**具體影響**：
- `canned_greetings`（快速問候比對層）設計時，姻緣類問法應優先納入預寫轉向台詞，不要等到 Phase 3 才臨時補
- `not_this_character` 除了「不是廟方人員/不是任何神祇」外，這裡特別需要明確「不是月老本人、不代替月老賜籤或牽紅線」
- `imagination_license`（虛構授權：神祕感能從哪來、不能宣稱什麼）在這裡的邊界要抓得比龍山寺更清楚——民俗傳說可以聊、但不能給出「你會在幾歲遇到誰」這類具體預測

## 0. 欄位結構（擴充版）

```jsonc
{
  "year": "1859",
  "event": "建廟",
  "detail": "...",              // ≤ 50 字，一句話講完
  "source": "...",
  "confidence": "..."           // 見下方分級
}
```

> JSONB 結構，**不需要跑 migration**——這是團隊內部約定，不是 DB schema 變更。

### confidence 分級

| 等級 | 意思 | 後續處理 |
|---|---|---|
| `official` | 廟方 / 官方文獻 / 學術考據一致 | 直接可進 `founding_facts` |
| `mainstream` | 主流說法，多數資料一致但非官方認證 | 可進，措辭保守（「相傳」「一般認為」） |
| `disputed` | 版本分歧、民間傳說、宗教解讀有爭議 | **先不進 founding_facts**，記在下方「爭議區」 |
