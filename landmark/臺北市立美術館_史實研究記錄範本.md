> 行政區：中山區
>
> ⚠️ 內容邊界提醒：北美館持續展出當代藝術，部分作品或策展主題可能涉及政治、性別、社會議題等敏感內容。查資料時建議只記錄**館舍本身**的沿革與定位（建館、建築特色、典藏方向），不要把特定當代展覽的爭議內容當作地標「史實」收錄——那類內容本質上會隨時間變動且立場多元，不適合寫死進 `founding_facts`。
>
> ⚠️ 另一個邊界：角色若被問到「這件作品好不好/值多少錢」，屬於**藝術鑑價/真偽判斷**，不應由角色給出確定性陳述，性質上與龍山寺「不預測吉凶」屬同一類「不做專業裁決」的邊界，建議之後設計人格時一併考慮進 `taboos`。

## 0. 欄位結構（擴充版）

`brain.landmark_souls.founding_facts` 原本是 `{year, event, detail}`，研究階段建議多記兩欄：

```jsonc
{
  "year": "1983",
  "event": "開館",
  "detail": "...",              // ≤ 50 字，一句話講完
  "source": "...",
  "confidence": "..."           // 見下方分級
}
```

> JSONB 結構，**不需要跑 migration**——這是團隊內部約定，不是 DB schema 變更。

### confidence 分級

| 等級 | 意思 | 後續處理 |
|---|---|---|
| `official` | 官方（北美館本身）文獻 / 學術考據一致 | 直接可進 `founding_facts` |
| `mainstream` | 主流說法，多數資料一致但非官方認證 | 可進，措辭保守 |
| `disputed` | 版本分歧，或涉及特定展覽/作品的評價爭議 | **先不進 founding_facts**，記在下方「爭議區」 |
