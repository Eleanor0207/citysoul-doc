## 0. 欄位結構（擴充版）

`brain.landmark_souls.founding_facts` 原本是 `{year, event, detail}`，研究階段建議多記兩欄：

```jsonc
{
  "year": "1996",
  "event": "遷建/開館",
  "detail": "...",              // ≤ 50 字，一句話講完
  "source": "...",
  "confidence": "..."           // 見下方分級
}
```

> JSONB 結構，**不需要跑 migration**——這是團隊內部約定，不是 DB schema 變更。

### confidence 分級

| 等級 | 意思 | 後續處理 |
|---|---|---|
| `official` | 官方（教育館本身）文獻 / 學術考據一致 | 直接可進 `founding_facts` |
| `mainstream` | 主流說法，多數資料一致但非官方認證 | 可進，措辭保守 |
| `disputed` | 版本分歧，或涉及科學爭議話題（如尚無定論的天文理論） | **先不進 founding_facts**，記在下方「爭議區」 |

## 3. 文化意義（對應 `cultural_significance`，自由敘述，建議 150–250 字）

草稿：
> 臺北市立天文科學教育館（臺北天文館）是臺灣最具代表性的科普教育地標與天文研究啟蒙重鎮。其歷史源自1938年臺北公會堂（中山堂）屋頂的4吋望遠鏡，歷經圓山天文臺時期半個世紀的夜觀歲月，於1997年遷至士林區現址。標誌性的金黃色半球體「宇宙劇場」建物已成為士林地標。天文館不僅典藏了歷史悠久的觀測儀器，更透過星象模擬、立體劇場與大型口徑望遠鏡，將浩瀚宇宙與常民生活距離拉近。它承載了跨世代臺北市民夜觀星空與探索未知的童年記憶，展現了理性好奇與科學探索的文化價值。

## 5. ⚠️ 爭議區（confidence = disputed 的項目集中放這裡）

> 常見爭議點：尚無科學定論的理論該如何呈現、占星/命理相關的模糊問法如何轉向。這些不會自動進 `founding_facts`。

| 內容 | 分歧點 | 是否涉及占星/命理類邊界問題 | 處理建議 |
|---|---|---|---|
| 西洋十二星座與占星運勢詢問 | 觀眾或玩家可能詢問「今天運勢如何」、「星座相配度」等占星命理話題。 | 是（涉及科普與占星命理界線） | **納入角色 `taboos` 禁忌範疇！** 角色**嚴禁預測運勢、吉凶或進行命理占卜**。應中性引導至「十二星座在天文學上的天球赤道位置與黃道十三星座之歷史由來」。 |
| 冥王星降級與行星定義演變 | 2006年國際天文學聯合會（IAU）將冥王星重分類為矮行星，民間與部分愛好者仍有情感爭論。 | 否（科學定義與大眾情感衝突） | 客觀記錄「國際天文學聯合會（IAU）於2006年通過之科學分類標準」，作為天文科普與科學定義演變之教育素材。 |
| 外星生命與UFO現象討論 | 大眾關注外星生命與未解UFO現象，科學界強調證據原則與宜居帶搜尋。 | 否（科普與大眾好奇心） | 保持中立科學視角，討論「繫外行星搜尋、宜居帶與SETI計劃」之科學探測事實，不進行未證實之陰謀論定論。 |
