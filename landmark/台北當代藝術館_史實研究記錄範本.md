# 台北當代藝術館（MOCA） 史實研究記錄範本

> 用途：查資料的過程中直接記錄在這裡，之後整批轉成 `landmarks/moca.yaml`（spirit_id 命名待定）→ 寫入 `brain.landmark_souls`。
> 這份文件本身不是正式資料來源，是給 Lead 審核前的**草稿暫存區**。
>
> 行政區：大同區
>
> ⚠️ 內容邊界跟北美館同一類：當代藝術館持續有變動展覽，只記錄**館舍本身**沿革（建築、建館歷程），不要把特定展覽的評價性內容當史實寫死進 `founding_facts`；當期展覽內容應走 B9 當日情境的內容路徑，不是史實層。
>
> ⚠️ 藝術鑑價/真偽判斷邊界同樣適用：角色不應對特定作品給出確定性評價或估價，比照北美館的處理方向。
>
> 補充：建物前身為日治時期「建成小學校」，之後曾作為台北市政府/市議會辦公廳舍，殖民時期歷史定性描述沿用保守措辭原則，敏感度低於榕錦時光/中正紀念堂一類，但仍走爭議區流程處理版本分歧。

## 0. 欄位結構（擴充版）

```jsonc
{
  "year": "1919",
  "event": "建成小學校落成",
  "detail": "...",              // ≤ 50 字，一句話講完
  "source": "...",
  "confidence": "..."           // 見下方分級
}
```

> JSONB 結構，**不需要跑 migration**——這是團隊內部約定，不是 DB schema 變更。

### confidence 分級

| 等級 | 意思 | 後續處理 |
|---|---|---|
| `official` | 官方（MOCA本身）文獻 / 學術考據一致 | 直接可進 `founding_facts` |
| `mainstream` | 主流說法，多數資料一致但非官方認證 | 可進，措辭保守 |
| `disputed` | 版本分歧，或涉及特定展覽/作品評價爭議 | **先不進 founding_facts**，記在下方「爭議區」 |

## 3. 文化意義（對應 `cultural_significance`，自由敘述，建議 150–250 字）

草稿：
> 台北當代藝術館（MoCA Taipei）是臺灣第一座以當代藝術為定位的藝術機構，更是古蹟活化再利用的跨時代範例。其紅磚建築本體歷經「日治建成尋常小學校」與「戰後臺北市政府辦公廳舍」的歷史演變，承載了近百年的教育與行政記憶。2001年轉型開幕後，正面作為當代藝術展館、兩翼作為建成國中校舍，創下罕見的「古蹟、學校與當代美術館」共構先例。MOCA 擺脫傳統美術館的典藏包袱，以前衛、實驗性與跨界的當代展演為核心，並與周邊赤峰街、中山巷弄文創聚落無縫對接，成為連結臺北歷史記憶與當代前衛視覺藝術之橋樑。

## 5. ⚠️ 爭議區（confidence = disputed 的項目集中放這裡）

> 常見爭議點：特定展覽/作品評價爭議、殖民時期建物用途描述分歧。這些不會自動進 `founding_facts`。

| 內容 | 分歧點 | 是否涉及鑑價/殖民史觀敏感性 | 處理建議 |
|---|---|---|---|
| 日治建成小學校階級差別敘事 | 當時建成小學校主要供日籍學生與少數臺籍地方菁英就讀，涉殖民教育不平等與階級隔閡討論。 | 是（涉及殖民教育歷史解讀） | 於 `founding_facts` 採客觀建築落成與學校成立歷史陳述，避免主觀價值評斷；若討論歷史脈絡，以「時代教育制度變遷」視角中性表達。 |
| 個別當代展覽作品之美學與政治評價 | 當代藝術展覽常涉及議題批判、前衛媒材或社會議題，外界觀點及評價極為多元且不一。 | 是（涉及當代藝術爭議與價值觀偏好） | **嚴禁將個別展覽或作品評價寫入 founding_facts**。角色不進行藝術鑑價、真偽判斷或權威評價，相關當期展覽走 B9 當日情境動態路徑。 |
| 美術館無常設館藏之經營定位 | 傳統觀點重視典藏功能，當代藝術館無典藏的經營模式曾引起藝術界對其定位與資源分配的討論。 | 否（藝術機構營運模式討論） | 中性記錄「以展示與跨界展演為核心之無典藏當代藝術館」之客觀營運模式。 |
