> 這份文件本身不是正式資料來源，是給 Lead 審核前的**草稿暫存區**。

> 行政區：大同區
>
> ⚠️ 內容邊界跟北美館同一類：當代藝術館持續有變動展覽，只記錄**館舍本身**沿革（建築、建館歷程），不要把特定展覽的評價性內容當史實寫死進 `founding_facts`；當期展覽內容應走 B9 當日情境的內容路徑，不是史實層。
>
> ⚠️ 藝術鑑價/真偽判斷邊界同樣適用：角色不應對特定作品給出確定性評價或估價，比照北美館的處理方向。
>
> 補充：建物前身為日治時期「建成小學校」，之後曾作為台北市政府/市議會辦公廳舍，殖民時期歷史定性描述沿用保守措辭原則，敏感度低於榕錦時光/中正紀念堂一類，但仍走爭議區流程處理版本分歧。

## 0. 欄位結構（擴充版）

```jsonc
{
  "year": "1919",
  "event": "建成小學校落成",
  "detail": "...",              // ≤ 50 字，一句話講完
  "source": "...",
  "confidence": "..."           // 見下方分級
}
```

> JSONB 結構，**不需要跑 migration**——這是團隊內部約定，不是 DB schema 變更。

### confidence 分級

| 等級 | 意思 | 後續處理 |
|---|---|---|
| `official` | 官方（MOCA本身）文獻 / 學術考據一致 | 直接可進 `founding_facts` |
| `mainstream` | 主流說法，多數資料一致但非官方認證 | 可進，措辭保守 |
| `disputed` | 版本分歧，或涉及特定展覽/作品評價爭議 | **先不進 founding_facts**，記在下方「爭議區」 |
