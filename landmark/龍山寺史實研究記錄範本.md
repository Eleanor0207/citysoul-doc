## 0. 欄位結構（擴充版）

`brain.landmark_souls.founding_facts` 原本是 `{year, event, detail}`，這裡建議研究階段就多記兩欄，方便之後判斷哪些能直接進史實層、哪些可能有爭議該轉進 `taboos`：

```jsonc
{
  "year": "1738",              // 可為約略年份，如 "清乾隆初年"
  "event": "建廟",              // 簡短標題
  "detail": "...",              // ≤ 50 字，一句話講完
  "source": "...",              // 來源出處
  "confidence": "..."           // 見下方分級
}
```

> 這是 JSONB，**不需要跑 migration**——結構調整是團隊內部約定，不是 DB schema 變更。真正要走 migration 的是欄位本身（如果之後要加索引或約束才需要）。

### confidence 分級（建議三級）

| 等級 | 意思 | 後續處理 |
|---|---|---|
| `official` | 廟方 / 官方文獻 / 學術考據一致 | 直接可進 `founding_facts` |
| `mainstream` | 主流說法，多數資料一致但非官方認證 | 可進，措辭保守（「相傳」「一般認為」） |
| `disputed` | 版本分歧、民間傳說、宗教解讀有爭議 | **先不進 founding_facts**，記在下方「爭議區」，交給 Lead 判斷是否轉為 `taboos` 條目或直接排除 |
