## 0. 欄位結構（擴充版）

```jsonc
{
  "year": "1937",
  "event": "工廠落成",
  "detail": "...",              // ≤ 50 字，一句話講完
  "source": "...",
  "confidence": "..."           // 見下方分級
}
```

> JSONB 結構，**不需要跑 migration**——這是團隊內部約定，不是 DB schema 變更。

### confidence 分級

| 等級 | 意思 | 後續處理 |
|---|---|---|
| `official` | 官方（園區管理單位/文化局）文獻 / 學術考據一致 | 直接可進 `founding_facts` |
| `mainstream` | 主流說法，多數資料一致但非官方認證 | 可進，措辭保守 |
| `disputed` | 版本分歧，或涉及殖民時期歷史定性 | **先不進 founding_facts**，記在下方「爭議區」 |

## 3. 文化意義（對應 `cultural_significance`，自由敘述，建議 150–250 字）

草稿：
> 松山文創園區（俗稱松菸）是臺灣近代工業遺產活化與都市空間轉型的經典地標。其前身為1937年建造的「臺灣總督府專賣局松山煙草工場」，採用日本初現代主義建築風格，以簡潔水平線條、紅磚面磚與面山環水設計著稱。廠區強調「工業村」精神，將製菸工廠與育嬰室、巴洛克花園、生態池結合，展現跨時代的勞工福利美學。關廠後，松菸浴火重生為臺北的「原創基地」，保存了連棟倉庫、高聳鍋爐房與中庭噴泉等古蹟本體，並透過跨界展演、設計品牌進駐與生態綠意，連結信義區摩天大樓群與傳統常民生活，成為兼具歷史歷史遺構與當代創意動能的都市綠洲。
