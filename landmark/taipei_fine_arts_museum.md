## 0. 欄位結構（擴充版）

`brain.landmark_souls.founding_facts` 原本是 `{year, event, detail}`，研究階段建議多記兩欄：

```jsonc
{
  "year": "1983",
  "event": "開館",
  "detail": "...",              // ≤ 50 字，一句話講完
  "source": "...",
  "confidence": "..."           // 見下方分級
}
```

> JSONB 結構，**不需要跑 migration**——這是團隊內部約定，不是 DB schema 變更。

### confidence 分級

| 等級 | 意思 | 後續處理 |
|---|---|---|
| `official` | 官方（北美館本身）文獻 / 學術考據一致 | 直接可進 `founding_facts` |
| `mainstream` | 主流說法，多數資料一致但非官方認證 | 可進，措辭保守 |
| `disputed` | 版本分歧，或涉及特定展覽/作品的評價爭議 | **先不進 founding_facts**，記在下方「爭議區」 |

## 3. 文化意義（對應 `cultural_significance`，自由敘述，建議 150–250 字）

草稿：
> 臺北市立美術館（北美館，TFAM）於1983年落成啟用，是臺灣第一座公立現代美術館，開創了國內現代與當代藝術展覽、典藏與研究的制度先河。正館建築由建築師高而潘設計，將傳統建築「斗拱」元素融匯為現代主義懸臂飛廊與「井」字形結構，象徵藝文活水源源不絕。北美館不僅完整典藏了臺灣近現代美術史的脈絡成果，更透過主辦「臺北雙年展」與「威尼斯雙年展臺灣館」，成功將臺灣當代藝術推向國際舞台。它既是市民賞析藝術與自然光影的美學空間，更是東亞當代視覺文化重要的前衛實驗基地。
