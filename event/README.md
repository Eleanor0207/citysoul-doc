# 當日情境與事件內容

B9 當日情境生成所使用的人工審核素材。

⚠️ SDD §3 限定輸入來源為：日期／節日、地標官方公開活動、人工審核素材。
**不得**使用即時天氣 API 或社群內容。

## 這裡不放主線劇情

主線劇情在 `story/`。兩者是不同的東西：

| | `event/`（這裡） | `story/` |
|---|---|---|
| 生命週期 | 每日輪替 | 一次性 |
| 因果關係 | 無 | 有前置鏈 |
| 玩家進度 | 不記錄 | 記錄在 `players_story_progress` |
| 資料表 | `public.daily_event_cache` | `brain.story_arcs` / `story_beats` |

同一個地標兩種內容都會有，但走不同的表與不同的生成路徑。
